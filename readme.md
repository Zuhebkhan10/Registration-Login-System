# 🔐 Login & Registration System (Tkinter)

This project is a simple Login and Registration System built using Python and Tkinter. It provides a basic graphical interface where users can create an account, log in, and reset their password if needed.

## 📌 About the Project

The goal of this project is to understand how user authentication works using file handling and GUI development in Python. It is designed for learning purposes and demonstrates the core logic behind login systems.

## ✨ Features

- User Registration (store username & password)
- Login Authentication
- Forgot Password (reset functionality)
- Simple and clean GUI using Tkinter
- Data stored in a text file (`users.txt`)

## 🛠️ Technologies Used

- Python
- Tkinter (for GUI)
- File Handling

## 📂 Project Files

- `login.py` → Main application file
- `users.txt` → Stores user credentials

## ▶️ How to Run

1. Install Python (if not already installed)
2. Open terminal in the project folder
3. Run the program:

python login.py
💡 How the System Works

Users can register with a username and password.

The credentials are stored in a text file.

During login, the system checks entered details with stored data.

If the user forgets the password, they can reset it using the "Forgot Password" option.
